指令:
cd /home/user/x5/lerobot

conda run --no-capture-output -n lerobot \
  python examples/phone_to_arx5/record.py \
  --phone-os ios \
  --can-interface can1 \
  --front-camera "" \
  --wrist-camera /dev/video4 \
  --num-episodes 3 \
  --episode-time-s 30 \
  --reset-time-s 10 \
  --task "使用手机遥操X5完成抓取任务"

推荐按下面的节奏采集。程序会自动开始每个 episode，不需要额外按“开
  始”。

  1. 看到 Recording episode N：
      - iPhone 按住 B1 控制机械臂。
      - 拖动 A3 控制夹爪。
      - 完成任务后松开 B1，立即在电脑终端按 → 或 n。
      - 当前 episode 会提前结束并保存，无需等满 30 秒。

  2. 看到 Reset the environment：
      - 按 H，让 X5 自动回到 Home。
      - 手动摆回物体。
      - 准备好后按 → 或 n，提前结束 reset，开始下一条数据。
      - 如果不按键，10 秒后也会自动开始下一条。

  各快捷键含义：

  - → 或 n：提前结束当前阶段。录制阶段会保存当前 episode；reset 阶段
    会提前开始下一条。

  - ← 或 r：当前 episode 有失误，丢弃并重录。
  - H：
      - 录制阶段按：丢弃当前 episode，随后自动回零并重录。
      - reset 阶段按：直接回零，上一条成功数据仍会保留。

  - Esc 或 q：正常结束整个采集并编码视频。录制阶段直接按会保存当前这
    条部分数据。

  - Ctrl+C：只建议紧急情况使用。

  最实用的循环是：

  完成任务 → 松开 B1 → 按 n
  看到 Reset → 按 H → 摆回物体 → 按 n
  开始下一条

  如果当前 episode 做坏了：

  按 H → 自动丢弃、回零 → 摆回物体 → 按 n → 重录

  不要完成任务后一直等待计时结束，否则静止画面和重复 action 也会被录
  入数据。
